# Product Catalog

A simple Product Catalog application built with React.

This project was originally created while I was learning the fundamentals of React. I recently revisited the project to clean up the code, improve the user interface, and deploy it as a small React application.

## Live Preview

**Website: [product-list-react-application.vercel.app](https://product-list-react-application.vercel.app/)**

## Features

- Add products to the catalog
- Delete products by clicking on them
- Press Enter to add a product
- Prevents empty products from being added
- Displays an empty state when there are no products
- Responsive design for mobile and desktop
- Simple and clean user interface

## Built With

- React
- JavaScript
- HTML
- CSS

## React Concepts Used

This project demonstrates some basic React concepts:

- Functional components
- `useState` hook
- Event handling
- Rendering lists with `map()`
- Conditional rendering
- Updating state immutably
- Handling keyboard events
